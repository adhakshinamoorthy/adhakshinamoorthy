## Engineering approach

- Make architecture decisions explicit and explain the trade-offs.
- Keep secrets out of source control and document safe configuration paths.
- Design failure handling, observability, and operational boundaries alongside features.
- Prefer small, testable abstractions and examples that people can run locally.
- State known limitations honestly instead of presenting prototypes as production systems.
